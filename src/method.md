# 數字怎麼量的

書裡談打法的數字都來自 [tsap-oo](https://github.com/jdh8/tsap-oo)，一個用 Rust 寫的十胡程式。這一篇說明量法，並列出每一個數字的指令，讓你可以重跑。

## 電腦怎麼打

對打用的電腦玩家叫 `HeuristicBot`。它替每一手牌打分數：胡數越高越好，散牌越多越差，缺口沒補滿要扣分。輪到它時，它把每一種合法的選擇都試一次，選分數最高的。

它只用牌桌上看得到的資訊：自己的手牌、四家亮出的牌組、棄牌堆。它不猜別人的手牌，也只往前看一步。網頁版的**提示**按鈕就是問它。

評分裡各項的比重是手調的。拿對局的結果重新估算（下面的擬合），估出來的比重和手調的差了兩三倍：散牌只有四成重，能胡的活牌有三倍重。把電腦換成這組比重，在 200,000 副相同的牌上有 59,981 副的打法不同，平均每副少得 0.005 分，95% 信賴區間是 −0.071 到 +0.060，分不出高下。另外兩組估出來的比重也沒有贏。評分只用來替同一手牌的幾種選擇排名次，比重差了這麼多，名次多半還是一樣。

另一個電腦 `MonteCarloBot` 會抽樣模擬：它從 `HeuristicBot` 評分最高的三個選擇出發，把看不到的牌隨機重發 128 次，每一次都打到這局結束，模擬的結果要好過一個標準誤，才換掉 `HeuristicBot` 的首選。它坐在三個 `HeuristicBot` 中間，和同一個位置換成 `HeuristicBot` 成對比較，3,200 副牌裡平均每副多得 0.148，95% 信賴區間是 −0.392 到 +0.689，跨過 0，分不出高下。分不出高下是資料不夠，不代表兩者一樣強，更不代表 `HeuristicBot` 打得最好。所以書裡的結論是「這樣打比那樣打好」，不是「這樣打最好」。

## 提示的數字怎麼讀

網頁版按**提示**之後，每張牌下面的數字是電腦估這一步比它的首選差幾胡。這個數字排得出名次，換不成固定的價錢。讓電腦把每一張可以打的牌都打到這一局結束，再依那個數字分組，實際少得的分數如下：

| 比首選差 | 這一局平均少得 |
|---|---:|
| 0.25 胡以內 | 0.0 分 |
| 0.25--0.5 胡 | 1.2 分 |
| 0.5--1 胡 | 1.9 分 |
| 1--2 胡 | 4.1 分 |
| 2--4 胡 | 1.6 分 |
| 4--8 胡 | 3.6 分 |
| 8--16 胡 | 8.3 分 |

- **差 0.25 胡以內分不出高下**。這一組有 106,420 個選擇，平均多得 0.04 分，標準誤 0.10。照自己的判斷打就好。
- **差 1--2 胡的比差 2--4 胡的貴**。小差距多半差在搭子和聽的活牌，大差距多半是多留一張散牌。電腦把散牌扣得重、把活牌算得輕，所以同樣是 1 胡，前者實際值 3 分左右，後者只值 0.6 分。
- **這張表只量過打牌**。吃、碰和過之間的數字沒有這樣量過。

## 五種量法

**發牌統計**。只發牌，不打牌，統計手牌的胡數和散牌。這種數字只和規則有關，和誰來打無關。

**自對局統計**。四個相同的電腦打很多局，統計結局。

**危險度**。四個電腦對打，在每一次打牌的時機，檢查每一種牌此刻落地會不會被胡。

**擬合**。四個電腦對打，每一次打牌的時機，記下四家手牌的胡數、散牌、缺口、搭子和聽的活牌，對上這一家這一局最後的得分，用最小平方法估出每一項值幾分。牌堆剩幾張、對手剩幾張手牌、對手桌上有幾胡也一起放進去估，免得把「牌局還早」算成手牌的功勞。同一批對局還做兩件事。一是把手牌依評分每 1 胡分一格，取各格得分的平均，這只用一半的牌局。二是每八次打牌取一次，把每一張可以打的牌都打到這一局結束，和電腦首選的得分比。

**成對比較**。比較新舊兩種打法時用這個方法：

1. 新打法坐一家，另外三家是舊打法，打一副牌。
2. 同一副牌再打一次，這次四家都是舊打法。
3. 比較同一個位置兩次的得分，差額就是新打法的功勞。

每一副牌用自己的亂數種子，莊家輪流。重複幾十萬副之後，報告差額的平均、標準誤和 95% 信賴區間。信賴區間整個在 0 以上才算新打法比較好。區間跨過 0 就是資料不夠，不能說「沒有比較差」。

要成對，是因為十胡的運氣成分很重。一個位置一局得分的標準差在 30 左右，而打法的改進往往只有 0.1 分。兩批不同的牌各打一次，差距會被牌運淹沒。

得分的單位是胡：胡 12 胡的贏家得 +36，另外三家各得 −12。

## 限制

- **對手是同一個電腦**。真人的習慣不同，尤其是留牌的習慣，會改變單吊和對倒的機率。
- **危險度的樣本彼此相關**。同一局裡相鄰的幾次打牌，檢查的幾乎是同樣的手牌，所以那一章沒有給信賴區間，只把差距很大的結果當成結論。
- **提示的數字不是價錢**。同樣差 1 胡，實際的得分差可以差到五倍，要看差在哪一項。
- **擬合估的是平均行情**。它比較的是不同的手牌，每一項只給一個價錢，項和項之間的牽連沒有算進去。照這些價錢調出來的電腦沒有比較強。
- **成對比較量的是整套打法的一處改動**。它說明這處改動在這個電腦身上有用，搬到別的打法上不保證一樣。
