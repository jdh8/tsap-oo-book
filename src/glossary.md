# 術語對照

英文是 [tsap-oo](https://github.com/jdh8/tsap-oo) 程式裡的用詞，方便對照原始碼。

| 術語 | 英文 | 意思 |
|---|---|---|
| 胡 | hu | 計分單位，也指贏牌 |
| 牌組 | meld | 算胡數的一組牌 |
| 順子 | run | 將士象、車馬包、三色或四色兵卒的合稱 |
| 對子 | pair | 兩張相同的牌，0 胡 |
| 暗刻 | concealed triplet | 發牌就拿齊的三張相同，3 胡 |
| 碰 | pong | 用公開的牌湊成三張相同，1 胡 |
| 暗槓 | concealed quad | 發牌就拿齊的四張相同，8 胡 |
| 槓 | kong | 手上三張加公開的第四張，6 胡，強制 |
| 吃 | eat | 用公開的牌湊成順子或對子 |
| 公開的牌 | offer | 剛摸出或剛打出、等四家處理的牌 |
| 牌堆 | pile | 還沒摸的牌 |
| 廢牌 | dead cards | 牌堆最底下不摸的 6 張 |
| 棄牌堆 | discards | 沒有人要的牌 |
| 莊家 | dealer | 拿 21 張、先打牌的人 |
| 下家、對家、上家 | | 右手邊、對面、左手邊 |
| 自摸 | | 胡自己摸的牌 |
| 放槍 | | 打出的牌被別人胡 |
| 天胡 | | 莊家發完牌就胡 |
| 流局 | exhausted | 牌堆剩 6 張，沒有人贏 |
| 相公 | foul | 沒有牌可打，賠每家 10 胡 |
| 大肚 | | 暗刻加上同一組順子的另外兩張，如 車車車馬包 |
| 散牌 | loose card | 手上不成組的牌 |
| 孤張 | | 和手上任何牌都搭不上的散牌 |
| 搭子 | | 只差一張就成順子的兩張牌 |
| 活牌 | live card | 還沒看到的牌 |
| 缺口 | | 離 10 胡還差的胡數 |
| 加胡 | | 一個牌組比 3 張 1 胡多出來的胡 |
| 安全線 | | 桌上的胡數 + 手牌張數 + 1 ≥ 10 |
| 聽牌 | wait | 只差一張就能胡 |
| 單吊 | | 聽一張牌湊成對子 |
| 對倒 | | 兩個對子，聽其中一對的第三張 |
