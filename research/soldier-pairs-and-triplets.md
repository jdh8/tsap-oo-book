# 兵卒的對子和三張

查核日期：2026-11-14。問題：同色的相同兵卒，例如 兵兵 或 卒卒卒，能不能像其他牌一樣湊成對子、三張相同（坎、碰）或四張相同（開招、槓），還是只能用在三色和四色的兵卒組裡。

## 結論

- **三張和四張：可以**。沒有來源排除兵卒。
- **對子：有爭議**。Board Game Arena 明文禁止，兩個維基百科條目都沒有這條規則。

本書和 tsap-oo 三種都允許，照的是維基百科的讀法。這一點維持現狀：對子是 0 胡，所以 Board Game Arena 那條規則只會影響哪些手牌算是全部成組、哪些吃法合法，不影響任何胡數。

## 出處

| 來源 | 兵卒的對子 | 兵卒的三張、四張 |
| --- | --- | --- |
| [Board Game Arena 的規則][bga] | **禁止**："Note that Soldiers cannot be melded into pairs!" 沒有說明理由。 | 沒有排除。通則是 "A set of cards with the same type AND color - melded into a PAIR, 3 of a kind or 4 of a kind"，對子那條附註是唯一的例外。 |
| [中文維基百科][zh] | 沒有禁止，推定允許：對子是吃牌可以湊成的五種牌型之一，兵卒沒有例外。 | 沒寫。提到了碰和槓（「同樣有吃、碰、槓」），但沒有定義。 |
| [英文維基百科][en] | 沒有禁止，推定允許：任何兩張相同的牌。 | 沒有禁止，推定允許：三張或四張相同的牌。 |
| [pagat][pagat] | 沒寫。只是概述，沒有牌組的規則。 | 沒寫。 |

中文維基百科列出的牌型，原文是：「三張三色的兵卒（三色兵）、四張四色的兵卒（四色兵）、三張同色的將士象（帥仕相）、三張同色的車馬包（俥傌炮）、對子」。

## 限制

- Board Game Arena 的說明讀的是英文版，`zh.` 開頭的網址會轉到英文的文件。它的胡數表（三張相同 1 / 3、四張相同 6 / 8、三色兵卒 3、四色兵卒 5）和本書的相同，所以講的是同一種遊戲。
- 英文維基百科條目裡牌組的定義，是經由摘要式的擷取讀的，沒有逐字讀，這一列的證據比較弱。
- pagat 連到 Wei-Hwa Huang 存檔的台灣規則，這一次沒有讀。接下來該查的就是那裡。
- 沒有找到寫明禁止兵卒成對的台灣文章，所以這是台灣牌桌上的規則，還是 Board Game Arena 自己的選擇，無從得知。

## 本書的選擇

本書和 tsap-oo 讓每一種牌都能湊成對子和三張相同，兵卒也不例外。改採 Board Game Arena 的規則，就要在吃牌和胡牌的排法兩處都不准兵卒成對。
